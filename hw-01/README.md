# Демонстрационный стенд (ДЗ 1, вариант 08)

Стенд для показа продукта клиентам. Поднимается одной командой перед показом и сносится одной командой после него, поэтому между показами не стоит денег. Переживает отказ одной машины.

## Состав стенда

- сеть `sidukov-08-net` и две подсети:
  - `sidukov-08-subnet-a` — ru-central1-b, 10.18.1.0/24
  - `sidukov-08-subnet-b` — ru-central1-d, 10.18.2.0/24
- три веб-сервера `sidukov-08-web-1..3` в двух зонах, nginx на порту 8024
- сервер приложения `sidukov-08-app` без публичного адреса, доступен только по внутренней сети
- NAT-шлюз `sidukov-08-nat` и таблица маршрутизации `sidukov-08-rt` — дают серверу приложения выход в интернет
- балансировщик `sidukov-08-lb`: принимает на порт 80, раздаёт на 8024, проверка состояния по HTTP

Все ресурсы получают метки `env=<окружение>` и `owner=<префикс>`.

## Что нужно заранее

- настроенный `yc` (заданы `folder-id` и `compute-default-zone`)
- `jq`, `envsubst` (пакет `gettext-base`), `curl`, `ssh`
- SSH-ключ `~/.ssh/id_ed25519.pub`

## Поднять стенд

```bash
./hw-01/create.sh
```

Через 3–4 минуты после завершения стенд готов. Дождаться готовности можно так:

```bash
until ./hw-01/check.sh; do sleep 15; done
```

Повторный запуск `create.sh` безопасен: уже созданные ресурсы пропускаются.

### Параметры create.sh

| Аргумент | Переменная | По умолчанию | Что задаёт |
|---|---|---|---|
| `--prefix P` | `PREFIX` | `sidukov-08` | префикс имён и метка owner |
| `--env E` | `ENV_NAME` | `stage` | метка env |
| `--web-count N` | `WEB_COUNT` | `3` | число веб-серверов |
| `--port N` | `APP_PORT` | `8024` | порт nginx |
| `--greeting W` | `GREETING` | `labwork` | слово на странице |

Через переменные окружения задаются также `ZONE_A`, `ZONE_B`, `CIDR_A` и `CIDR_B`.

Приоритет такой: аргумент важнее переменной окружения, переменная окружения важнее значения по умолчанию.

```bash
./hw-01/create.sh --web-count 2
WEB_COUNT=2 ./hw-01/create.sh
```

## Проверить стенд

```bash
./hw-01/check.sh; echo $?
```

Сценарий выполняет три проверки:

1. балансировщик отвечает кодом 200;
2. ответили все веб-серверы;
3. сервер приложения доступен с web-1 по внутреннему адресу.

Код возврата 0 означает, что прошли все проверки. Код 1 означает, что хотя бы одна не прошла.

Если `check.sh` использовался с другим префиксом или числом машин, их нужно передать переменными, например `PREFIX=... WEB_COUNT=... ./hw-01/check.sh`.

## Что делать, если check.sh вернул 1

| Строка вывода | Вероятная причина | Что сделать |
|---|---|---|
| балансировщик не найден | стенд не поднят или снесён | `./hw-01/create.sh` |
| балансировщик отвечает: 000 | машины ещё настраиваются | подождать 1–2 минуты и повторить |
| ответили машины N из M | на части машин не работает nginx | посмотреть состояние целевой группы командой `yc load-balancer network-load-balancer target-states --name sidukov-08-lb --target-group-id <id>`, затем зайти на машину со статусом UNHEALTHY и выполнить `sudo systemctl status nginx` и `sudo systemctl start nginx` |
| сервер приложения недоступен с web-1 | на нём ещё работает cloud-init или нет выхода через NAT | `ssh -J student@<IP web-1> student@<IP app> "cloud-init status --long"`; если статус error, проверить привязку таблицы `sidukov-08-rt` к `sidukov-08-subnet-a` и пересоздать машину |

## Снести стенд

```bash
./hw-01/destroy.sh
```

Сценарий удаляет все ресурсы с меткой `owner=sidukov-08`. Свой префикс можно передать аргументом: `./hw-01/destroy.sh --prefix <префикс>`. В конце выводятся диски, не подключённые ни к одной машине: загрузочные диски не получают меток, поэтому их стоит проверить вручную.

После сноса убедитесь, что ничего не осталось:

```bash
yc compute instance list
yc compute disk list
yc vpc network list
yc load-balancer network-load-balancer list
```

## Файлы

- `create.sh` — поднимает стенд
- `check.sh` — проверяет стенд, возвращает 0 или 1
- `destroy.sh` — сносит стенд
- `cloud-init.tpl.yaml` — шаблон настройки машин; из него при запуске генерируется `cloud-init.yaml`, который в репозиторий не попадает
- `расхождения.md` — список того, чего не умеет сценарий
